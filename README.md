# Pengingat Kerja (Android, Kotlin)
1. Buka folder ini di Android Studio (versi terbaru), tunggu Gradle sync.
2. Colok HP (USB debugging aktif) lalu Run, atau Build > Build APK(s).
3. Saat pertama dibuka, izinkan Notifikasi dan "Notifikasi layar penuh".
4. Widget: tekan lama layar utama > Widget > Pengingat Kerja.

Fitur: input cepat bahasa Indonesia, kegiatan berulang, catatan, pengingat awal (5/10/30/60 menit sebelumnya),
widget 3 kegiatan berikutnya, kelompok Hari ini/Mendatang/Terlewat/Selesai, pilih nada alarm,
tunda 5/10/15 menit, getar, mode gelap otomatis, alarm tetap bunyi saat aplikasi ditutup.
